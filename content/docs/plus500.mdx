## How to connect

<Steps>
  <Step title="Open Add account">
    [Accounts](/accounts) → **Add account** → Plus500. Premium is required.
  </Step>
  <Step title="Email, password, server">
    Use the Plus500 login and environment the broker issued. Verify and add the account.
  </Step>
</Steps>

Complete Plus500 account verification and product agreements on [plus500.com](https://www.plus500.com/) before API / platform access works.
