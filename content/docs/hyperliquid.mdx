Crypto perps and tokenized indexes. Algorithms and webhooks. No copy trade. Webhook `platformType`: `hyperliquid`.

## How to connect

<Steps>
  <Step title="Create an API wallet">
    [app.hyperliquid.xyz](https://app.hyperliquid.xyz) → Settings → API. The agent key can trade and cannot withdraw.
  </Step>
  <Step title="Open Add account">
    [Accounts](/accounts) → **Add account** → Hyperliquid. Premium is required.
  </Step>
  <Step title="Network">
    Testnet or Mainnet.
  </Step>
  <Step title="Wallet + agent key">
    Master wallet address (`0x…`) and the API wallet private key. Verify and add.
  </Step>
</Steps>

<Warning>
  Do not size XYZ100 like 1 NQ. See [Crypto](/crypto).
</Warning>

## How to sign contracts

There is no CME agreement. You accept Hyperliquid’s terms in the app and authorize the API wallet. That is the “contract.”
