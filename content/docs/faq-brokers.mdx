<AccordionGroup>
  <Accordion title="Which brokers can I connect?">
    ProjectX, Tradovate, NinjaTrader, Rithmic, TradeLocker, Plus500, Oanda, Hyperliquid, CQG, MatchTrader, Volumetrica, cTrader (beta), and MetaTrader 5. Full table: [Brokers](/brokers).
  </Accordion>
  <Accordion title="Which platforms support copy trading?">
    **ProjectX**, **Tradovate**, **NinjaTrader**, **Rithmic**, and **Volumetrica**. Cross-platform groups among those five work. Other brokers can still run algorithms and webhooks.
  </Accordion>
  <Accordion title="Can I use Oanda with Hextrade algorithms?">
    Oanda connects for forex / CFDs and webhooks. It is **excluded** from futures algorithms.
  </Accordion>
  <Accordion title="How do I connect an account?">
    Open [Accounts](/accounts) → **Add account** → choose the broker → finish that platform’s login or API flow. Tradovate demo accounts can also be created from **Tools**.
  </Accordion>
  <Accordion title="The account shows an error after I connect it.">
    Re-open Add account and confirm environment (demo vs live), server, and password. For Rithmic, select the account after login. Discord: [hextrade](https://discord.com/invite/hextrade).
  </Accordion>
</AccordionGroup>
