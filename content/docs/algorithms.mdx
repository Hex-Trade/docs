Algorithms live on [dash.hextrade.io/algos](https://dash.hextrade.io/algos). Each row is a dashboard ID such as `NQRAPTOR` or `ESRAPTORV3`.

## Naming format

`[instrument][strategy][version]`

- `NQRAPTOR` — Nasdaq futures + Raptor
- `ESRAPTORV3` — third ES Raptor revision
- `NQRAPTOR22` — 22-minute NQ Raptor variant

## Badges

| Badge | Meaning |
| --- | --- |
| **Prop Firm Ready** | Intraday style, suitable for many prop-firm rules |
| **Non-Prop** | Typically holds overnight — check your firm’s rules |
| **Overnight** | Designed to hold outside regular hours |
| **Beta Testing** | Newer strategy; monitor closely |
| **Deprecated** | Kept for existing connections; prefer a newer family |
| **Short Term** / **24/7 Scalper** | High-frequency or always-on variants (often in Advanced) |

## Advanced / experimental

The **Advanced** section on Algos includes hidden, beta, and third-party IDs such as `ESBOSS`, `ESVIPER`, `NQVIPER`, `ESVORTEX`, `NQCORE`, `GCFLUX`, `GCNOVA`, `NQHAS`, `GCHAS`, `NQDRIFT`, and `GCBB`. Use extra caution.

## Supported algorithm brokers

Futures algorithms run on connected futures-capable brokers. **Oanda is excluded.** See [Brokers](/brokers).

## How to connect

<Steps>
  <Step title="Browse Algos">
    Open [dash.hextrade.io/algos](https://dash.hextrade.io/algos) and pick a variant.
  </Step>
  <Step title="Read the metrics">
    Check APY, win rate, total trades, and P&L on the detail page.
  </Step>
  <Step title="Confirm the broker">
    The variant must support a [connected account](/accounts).
  </Step>
  <Step title="Attach and set risk">
    In **Connected Accounts**, select the account, set risk, then activate.
  </Step>
</Steps>

<Warning>
  Review history and set risk before going live. Past performance does not guarantee future results. Start with micro size to confirm the integration.
</Warning>
