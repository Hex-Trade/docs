## What you can do

- **Connect brokers** — ProjectX, Tradovate, NinjaTrader, Rithmic, TradeLocker, and more on [Accounts](/accounts).
- **Run algorithms** — Browse families like Raptor and Blaze, then attach a connected account.
- **Copy trade** — One master account, many followers, each with its own risk multiplier.
- **Build a portfolio** — Mix algorithms, review the seven analysis tabs, then deploy.
- **Trade manually** — Full-screen chart and order ticket on [Trading](/trading).
- **Use TradingView** — Send alerts to Hextrade with a webhook payload.

## How the dashboard is organized

The sidebar matches these docs:

| Dashboard page | Use it for |
| --- | --- |
| **Accounts** | Connected brokers, balances, add account |
| **Algos** | Catalog, metrics, attach an account |
| **Copy Trade** | Master / follower groups |
| **Portfolio** | Mix, optimize, and deploy strategies |
| **Trade** | Manual orders and charts |
| **Analytics** | Live P&L and account performance |
| **Calendar** | Macro events that can move markets |
| **Subscriptions** | Plan, limits, algorithm access |
| **Settings** | Profile, 2FA, notifications, Aqua theme, API token |
