## Futures

Start on **micros**. Raise quantity only after you have lived with the dollar swing.

| Goal | Typical start |
| --- | --- |
| Learn an algorithm | 1 micro (MNQ, MES, MGC) |
| Small personal account | 1–2 micros |
| Match a mini | 10 micros (5 for Nikkei) — or 1 mini if margin allows |

Formulas live on [Futures](/futures).

## CFDs

Convert from a micro on [CFDs](/cfds). If the broker pt/lot is not the Hextrade default, recompute lots.

## Copy-trade followers

Do not raise the master’s size to “help” a larger follower. Leave the master conservative and set each follower’s **risk multiplier** (`0.5`, `1.0`, `2.0`). See [Copy trading](/copy-trading).

## Prop accounts

Daily loss and trailing drawdown are counted in dollars. One extra mini can be a full daily-loss hit. Details: [Prop firm rules](/prop-firm-rules).

<Warning>
  Switching MNQ → NQ at the same quantity is a 10× risk change. Treat it like a new strategy.
</Warning>
