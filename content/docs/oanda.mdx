Forex and CFDs. Webhooks yes. **Not used on futures algorithms.** No copy trade. Webhook `platformType`: `oanda`.

## How to connect

<Steps>
  <Step title="Create an API key">
    Log in at [oanda.com](https://www.oanda.com/) → manage API access. Create a token for demo or live.
  </Step>
  <Step title="Open Add account">
    [Accounts](/accounts) → **Add account** → Oanda. Premium is required.
  </Step>
  <Step title="Demo or Live plus API key">
    Verify, select the account(s), and add them.
  </Step>
</Steps>

## How to sign contracts

Complete OANDA account opening and accept their client agreement. API tokens only work after the account is active.
