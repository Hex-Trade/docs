## NQ Variants Explained

Multiple NQ Blaze versions are available. Each iteration reflects changes to logic and trade behavior:

- **Blazer** — the original NQ 1-hour strategy.
- **Blaze** — refined version.
- **BlazeV2** — second-generation improvements.
- **BlazeV3** — latest iteration with the most recent adjustments.

Check the individual algorithm detail pages on [dash.hextrade.io/algos](https://dash.hextrade.io/algos) to compare metrics across versions before choosing one.
