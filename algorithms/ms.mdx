# Ms

Ms is a **beta** Nasdaq 100 futures algorithm. Monitor it closely if you connect it.

---

## Available Variants

| Dashboard ID | Instrument | Notes |
|--------------|-----------|-------|
| `NQMS` | Nasdaq 100 (NQ) | Beta |

---

## How to connect

1. Go to [dash.hextrade.io/algos](https://dash.hextrade.io/algos) and open `NQMS`.
2. Review metrics, connect a futures-capable account, set risk, and activate.

<Warning>
  Beta algorithms can change behavior as they are tuned. Start with micro size and watch the first sessions.
</Warning>
