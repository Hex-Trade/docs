Hextrade provides a broad algorithm library across equity-index futures, commodities, and crypto instruments. Algorithms are listed on [dash.hextrade.io/algos](https://dash.hextrade.io/algos) by their dashboard ID (for example `NQRAPTOR` or `ESRAPTORV3`).

## Naming format

Dashboard IDs follow:

`[instrument][strategy][version]`

Example: `NQRAPTOR` means Nasdaq futures (`NQ`) + Raptor. `ESRAPTORV3` is the third ES Raptor revision. `NQRAPTOR22` is the 22-minute NQ Raptor variant.

## Badges

The Algos page tags each strategy:

| Badge | Meaning |
|-------|---------|
| **Prop Firm Ready** | Intraday style, suitable for many prop-firm rules |
| **Non-Prop** | Typically holds overnight — check your firm's rules |
| **Overnight** | Designed to hold outside regular hours |
| **Beta Testing** | Newer strategy; monitor closely |
| **Deprecated** | Kept for existing connections; prefer a newer family |
| **Short Term** / **24/7 Scalper** | High-frequency or always-on variants (often in Advanced) |

## Advanced / experimental

A separate **Advanced** section on the Algos page includes hidden, beta, and third-party IDs such as `ESBOSS`, `ESVIPER`, `NQVIPER`, `ESVORTEX`, `NQCORE`, `GCFLUX`, `GCNOVA`, `NQHAS`, `GCHAS`, `NQDRIFT`, and `GCBB`. Use these with extra caution.

## Supported platforms

Futures algorithms run on connected futures-capable brokers: ProjectX, Tradovate, NinjaTrader, Rithmic, TradeLocker, Plus500, Hyperliquid, CQG, MatchTrader, Volumetrica, cTrader, and MetaTrader 5. **Oanda is excluded** from futures algorithms. See [Supported Brokers](/supported-brokers).

## How to connect any algorithm

1. Browse available algorithms at [dash.hextrade.io/algos](https://dash.hextrade.io/algos).
2. Open the algorithm detail page and review its performance metrics.
3. Navigate to **Connected Accounts** and link one of your [broker accounts](/automated-trading/trading-accounts).
4. Set an appropriate risk level before activating.

<Warning>
  Always review an algorithm's performance history and set risk carefully before going live. Past performance does not guarantee future results.
</Warning>
